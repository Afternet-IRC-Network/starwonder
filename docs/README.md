# StarWonder Docs

A web-based, slow-paced space trading & conquest game in the spirit of the **classic '90s
BBS space-traders**, built on an **xkcd #195 ("Map of the Internet")** style fractal galaxy
map.

This folder uses **PARA** organization:

| Folder | Holds | Rule of thumb |
|--------|-------|---------------|
| `0-Projects/`  | Active efforts with a goal and an end state | "I'm working on this now" |
| `1-Areas/`     | Ongoing responsibilities with no end date   | "I maintain this forever" |
| `2-Resources/` | Reference material & topics of interest     | "Useful to know / look up" |
| `3-Archives/`  | Anything from the above that's now inactive  | "Done or abandoned" |
